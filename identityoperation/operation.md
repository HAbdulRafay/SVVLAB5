| OP ID | Operation | Purpose |
| --- | --- | --- |
| OP01 | Perform Sensor Self-Check | Verify that all essential sensors and environmental-control devices work correctly at power-on before conservation can begin. |
| OP02 | Register Artifact and Load Profile | Record the artifact's identification and load its required environmental limits so it can be monitored. |
| OP03 | Monitor Environmental Sensors | Continuously read temperature, humidity, light, vibration, door and power status. |
| OP04 | Start Conservation Process | Begin normal conservation only when the door is closed and the artifact profile is loaded. |
| OP05 | Compare Readings with Limits | Check actual temperature and humidity against the artifact's permitted ranges. |
| OP06 | Correct Temperature and Humidity | Send correction commands to the environmental-control mechanism to bring out-of-range values back. |
| OP07 | Verify Environmental Recovery | Confirm through sensor readings (not just the command) that conditions are back in range within the recovery period. |
| OP08 | Activate Artifact Protection | Reduce light exposure and activate additional environmental controls when correction fails in time. |
| OP09 | Generate Operator Alert | Notify the museum operator about protection-level or abnormal situations. |
| OP10 | Suspend Risky Activities on Vibration | Stop activities that could increase risk to the artifact when significant vibration is detected. |
| OP11 | Verify Vibration Stabilization | Confirm vibration stayed below the threshold for the full stabilization period before resuming. |
| OP12 | Suspend Conservation on Door Opening | Immediately stop normal environmental operation while the chamber door is open. |
| OP13 | Revalidate Conditions After Door Closure | Check artifact environmental conditions and sensor status before resuming normal operation. |
| OP14 | Switch to Emergency Power | Keep the chamber running from the backup source when main power is lost. |
| OP15 | Record Incident and Perform Safe Shutdown | Log the power-loss incident and shut the system down safely when no emergency power exists. |
| OP16 | Authorize Artifact Removal | Allow the operator to remove the artifact only when the chamber is safe and no protection response is active. |
